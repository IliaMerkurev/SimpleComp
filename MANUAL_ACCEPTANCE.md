## Manual scene checks

| Check | Steps | Expected result |
| --- | --- | --- |
| Capacity-one reuse | Set Rows/Columns/Layers to 1. Call SetFillLevel(1), wait for completion, SetFillLevel(0), then repeat several times. Also extract the single element and call SetFillLevel(1) again. | Each fill produces one visible element and one completion for a new ticket. Empty stays empty; the same level can refill after extraction. |
| Extraction during scale animation | Use a longer scale duration. Fill several elements, extract one before completion, then wait. Repeat while other resources arrive. | Extracted element never reappears; remaining animations follow their tickets through compaction; no completion for the removed ticket. Extracted transform uses full target scale. |
| Concurrent reservations | Reserve two tickets, fill other slots, extract a lower slot, then confirm the two original tickets in reverse order. | Both arrivals resolve their current slot; no resource is lost or assigned another ticket. |
| Rapid FillLevel edits | Enable bEnableFillAnimation. Animate 0 -> 1 -> 0.2 -> 0 -> 1 with stagger and long scale durations. Repeat with direct Blueprint property writes. | Counts converge to the requested target without ghost instances or stale callbacks. External reservations remain valid and can temporarily exceed the target. |
| Event identity | Print RequestSlot results and OnSlotFilled arguments through slot reuse, extraction, and compaction. | Completion arguments equal the original request tickets, not current HISM indices. OnActorSpawned SlotID retains its documented physical-index meaning. |
| Random scale | Enable non-uniform random scale, reserve/inspect a destination, confirm arrival, wait, deform, then compact by extracting another element. | The resource retains its random scale and rotation throughout; the final destination and spawned actor use the same full target scale. |
| Safe resize/rebuild | Populate a stack and leave a reservation in flight. Increase capacity/change mesh/padding; shrink to a capacity that fits occupancy, then below occupancy. | Existing tickets, reservations, and animations survive supported edits. An undersized resize is rejected with a log message and applied dimensions restored. |
| Failed conversion | Fill a stack. Try SpawnActors with an unset class, then with a valid class. Also use a class that destroys itself in BeginPlay to exercise failed conversion. | Invalid/failed spawn retains resource and ticket. Retrying can convert it. Successful spawn removes exactly one resource before message/event callbacks. Completion of waves does not promise zero remaining resources. |
| Retimed notifies | Author a sequence extent of 2 seconds with markers at 0, 0.5, 1, and 2. Play with PlaybackDuration 4. | Markers cross at playback times 0, 1, 2, and 4 respectively (subject to frame advancement); each pose/update is evaluated once per playback update. |
| Loop boundaries and reverse | Play that sequence looping in both directions. Choose a PlayRate that crosses more than two loops in one frame; also check exact endpoint landings. | Traversal order is preserved. Forward crossing dispatches end then zero; reverse dispatches zero then end. Each crossed cycle emits its markers. Zero rate does not consume initial endpoint markers. |
| Pause, seek, duration | Pause, seek to half the playback duration, resume, edit duration, Stop, then K2 Play. | Seek updates pose without notifies/Finished; resume continues; active duration edits preserve normalized progress; Stop and K2 Play retain position. |
| Finished chaining | In Finished, start another sequence on the same component. Also stop/seek/restart from a notify handler. | The new animation remains active. The obsolete playback dispatches no further Update/Finished after invalidation. |
| Repeated K2 controls | Use PlayFromStart, Play, Pause, Resume, ReverseFromCurrent, ReverseFromEnd, and Stop repeatedly; exercise several nodes on one component. | Continue/reverse-current do not rewind. Controls do not duplicate events; replacement detaches earlier playback subscriptions. |
| K2 pins and saved assets | Reopen existing graphs. Use duplicate notify names and names matching Update, Finished, Play, CurrentTime, Default, and Selection. Edit the selected sequence in the node's Details. | One pin per unique notify; built-in pins remain distinct. Double time outputs are correct on Update/Finished/notifies. Node reconstructs/compiles without broken connections. Reconstruct affected old nodes if required and record compatibility issues. |
| Local/World transforms | Place animation, rolling, and stack components under translated, rotated, and scaled parents; try absolute rotation where supported. | Local animation follows the parent; World animation uses the world baseline. Sphere rolling axis and stack deformation remain spatially consistent. Wheel preserves initial orientation. |
| Runtime deformation | Change None/ManualCurve/Inertia, TiltScale, control transforms, mesh, padding, scale, and collision through Details/Blueprint. Call RefreshSettings for immediate application. | Settings update without discarding occupancy. Idle raw edits synchronize within 0.1 seconds; active modes update per frame. Inertia remains finite during long frames; review its changed visual response. |
| Collector shape/lifecycle | Start with an already-overlapping resource. Switch Sphere/Box at runtime, move a multi-component resource through the volume, and destroy an in-flight resource. | Active volume follows the selection; one collector assigns the same live ticket once; the destroyed resource's reservation is released. Live flights survive collector destruction and remain responsible for confirming/cancelling. |
| Zero radius | Move Wheel/SphereRoll with radius 0 and negative radius, then restore a positive value. | No invalid transform; rolling is suspended and resumes without a catch-up jump. Wheel steering still responds while stopped/disabled. |
| FollowConstraint | Exercise Free/Locked/Limited location and rotation axes, swapped limits, and zero smoothness. | Locked world location is retained; Limited offsets use target-relative centimeters in world axes. Explicit limits take precedence if incompatible with rope length. Zero smoothness turns instantly; positive values converge. |
| Spawner restart/settings | Restart flow while running, change flow mode/interval/duration, then stop. Have a spawned actor stop/restart the spawner or destroy itself from its message callback. | Old timers/bursts do not continue. Active raw flow edits restart scheduling within 0.1 seconds. Invalid flow interval produces one burst per phase. Destroyed actors receive no subsequent physics access. |
| Rotation fallback | Use ToTarget without an actor, with a static TargetLocationOffset; switch in/out of displacement mode. | Static world target works; movement direction does not use stale displacement from unrelated modes. |
